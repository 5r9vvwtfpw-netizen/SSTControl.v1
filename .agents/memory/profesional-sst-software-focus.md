---
name: Profesionales SST y protección del software
description: Alcance permanente del acuerdo de confidencialidad para profesionales que reciben acceso al portal
---

El acuerdo para Profesionales en SST debe ser principalmente de confidencialidad, propiedad intelectual y uso restringido del software SST-Colombia. La persona recibe una autorización limitada de uso, no una alianza, relación laboral, prestación de servicios ni representación. El documento no debe usar la palabra LSO.

La protección central comprende código, arquitectura, estructura de datos, interfaces, módulos, flujos, automatizaciones, integraciones, metodologías, documentación, controles, reportes, precios, estrategias y conocimiento reservado. Debe impedir copiar, extraer, hacer ingeniería inversa o usar esa información para desarrollar, apoyar, mejorar o comercializar productos que reproduzcan o compitan con la plataforma, sin prohibir el ejercicio profesional independiente ni el uso de conocimientos generales no confidenciales. La protección de datos personales y sensibles es complementaria, porque el objetivo principal es proteger el software.

**Why:** El usuario aclaró que el riesgo principal es que un profesional con acceso al portal se convierta en competidor o replique el producto, no que el documento funcione principalmente como acuerdo de tratamiento de datos de clientes.

**How to apply:** En futuras modificaciones de este módulo, revisar primero el software, la propiedad intelectual, el acceso y la competencia basada en información confidencial; mantener los datos SST como obligación secundaria y conservar la denominación Profesional en SST.
