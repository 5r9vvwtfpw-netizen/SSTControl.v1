LSO and external LSO accounts must be able to manage the SST training program (standard 1.2.1) and SST communications (standard 2.8.1), not only read them. Keep every write scoped to the company validated through the LSO's active assignment.

**Why:** The user explicitly requested complete management access for these two standards so licensed professionals can manage the modules.

**How to apply:** Grant the relevant create, edit, delete, and send permissions to both LSO roles for these module domains. Preserve the shared LSO permission matrix and the effective-company validation on every API route; do not turn assigned-company access into global access.
