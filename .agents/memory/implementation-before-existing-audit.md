---
name: Auditoría antes de implementar
description: Revisa controles y flujos existentes antes de añadir o duplicar funcionalidades.
---

Antes de implementar una solución, inspeccionar los flujos actuales de interfaz, autenticación, rutas y datos para separar lo que ya existe de las brechas reales; corregir las brechas sin duplicar controles.

**Why:** el usuario pidió explícitamente revisar bien si algo ya existe antes de implementarlo.

**How to apply:** en este proyecto, informar brevemente qué controles existentes se encontraron y qué falta antes de modificar código, sobre todo en cambios de acceso, seguridad y cumplimiento.
