---
name: PESV quarterly report sequencing
description: Rules for adding the Superintendencia quarterly reports one at a time using existing modules.
---

Implement only the next report the user has described and approved. Treat the reports menu as a generator/connector, not as a place to create a separate data module for every requested evidence item. First inspect the source modules and reuse or enrich them. Keep a consistent quarterly-report pattern: selected period, source completeness, exact PESV step/module for missing data, and standardized export. Never invent evidence or a legal representative's approval; require a deliberate confirmation before using a stored signature. For lesson dissemination, use accident investigations as the source, Comunicaciones SST as the distribution channel, and Portal de Empleados for read confirmation and recipient feedback; a read receipt alone is not feedback.

**Why:** The user wants one coherent report generator derived from existing modules, not duplicate data-entry modules, and will approve reports one at a time. Certifications also have legal significance.

**How to apply:** Before each next report, wait for its source requirement, inspect the relevant current modules, identify missing data capture there, then add only that report to the quarterly generator. Do not design future reports in advance. Explain missing fields with a direct link to the relevant PESV step; for signed outputs, use the company's configured representative and request explicit confirmation.
