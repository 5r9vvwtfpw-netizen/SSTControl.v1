---
name: PESV quarterly report sequencing
description: Rules for adding the Superintendencia quarterly reports one at a time using existing modules.
---

Implement only the next report the user has described and approved. Treat the reports menu as a generator/connector, not as a place to create a separate data module for every requested evidence item. First inspect the source modules and reuse or enrich them. For lesson dissemination, use accident investigations as the source, Comunicaciones SST as the distribution channel, and Portal de Empleados for read confirmation and recipient feedback; a read receipt alone is not feedback.

**Why:** The user wants a coherent set of quarterly reports derived from existing modules and will provide requirements one report at a time.

**How to apply:** Before each next report, wait for its source requirement, inspect the relevant current modules, identify missing data capture there, then add only that report to the quarterly generator. Do not design future reports in advance.
