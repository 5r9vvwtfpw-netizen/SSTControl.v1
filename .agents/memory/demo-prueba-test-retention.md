---
name: DEMO-PRUEBA test retention
description: Política acordada para conservar evidencia creada durante pruebas funcionales.
---

En DEMO-PRUEBA, cuando el usuario solicite una prueba funcional para revisar un informe o resultado, crear evidencia de negocio claramente marcada como prueba y conservarla para su revisión. No basta con probar solo con una cuenta temporal.

No alterar registros existentes que no estén claramente identificados como pruebas ni inventar datos que puedan parecer hechos reales. Sí se pueden retirar cuentas temporales de acceso y otros recursos técnicos que no sean evidencia revisable.

**Why:** El usuario revisa personalmente los registros y documentos generados durante las pruebas.

**How to apply:** Crear la evidencia por los módulos/rutas normales, marcar vehículo, conductor, acta y siniestro como ficticios cuando corresponda, conservar esos registros y distinguir cualquier muestra descargable del informe oficial completo.
