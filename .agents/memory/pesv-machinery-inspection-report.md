name: PESV machinery inspection detail and report
description: Keep H06 checklist answers aligned in the employee portal, administrative detail, and individual PDF.
---

Use one shared H06 checklist definition for the worker form, administrative quick view, and PDF report. Individual report queries must constrain both the inspection ID and the authorized company.

**Why:** Separate labels or answer keys can make the submitted record, quick view, and formal report disagree; filtering only by record ID risks exposing another company's inspection.

**How to apply:** Reuse the shared checklist definition when changing H06 fields, resolve report scope through the authorized-company helper, and keep the inspection-ID/company-ID predicates together.
